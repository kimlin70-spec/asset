# 내 자산 현황

국내주식·해외주식·코인·채권·현금·기타 자산과 부채를 원화로 합쳐 순자산과 추이를 보는 개인용 웹앱입니다.
시세(주가·코인·환율)만 자동으로 받고, 보유 현황과 거래는 직접 입력합니다.

- 앱(이 저장소, 공개): 빌드 없는 정적 웹앱, GitHub Pages로 배포
- 내 데이터(비공개 저장소): 장부·시세·날짜별 합계 JSON
- 자세한 규칙: [SPEC.md](SPEC.md)

## 지금 상태

4단계 중 1단계(장부 계산 모듈과 단위 테스트)까지 만들었습니다. 아직 화면은 없습니다.
설정 방법(저장소·토큰 만들기부터 첫 입력까지)은 화면이 생기는 2단계에서 이 문서에 씁니다.

## 개발자용: 테스트 실행

Node.js 20 이상에서 외부 패키지 없이 실행됩니다.

```bash
node --test
```
