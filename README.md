# 내 자산 현황

국내주식·해외주식·코인·채권·현금·기타 자산과 부채를 원화로 합쳐 **순자산과 추이**를 보는 개인용 웹앱입니다.
시세(주가·코인·환율)만 자동으로 받고, 보유 현황과 거래는 직접 입력합니다. 엄격한 가계부가 아니라 **대략적인 현황과 추이**가 목적입니다.

- 앱 주소: https://kimlin70-spec.github.io/asset/
- 앱 코드(이 저장소, 공개): 개인 자료는 없습니다.
- 내 자료(내가 만드는 비공개 저장소): 장부 `ledger.json`, 시세 `prices.json`, 날짜별 합계 `history.json`
- 자세한 규칙: [SPEC.md](SPEC.md)

## 처음 설정 (윈도우 PC, 10분)

### 1. 비공개 저장소 만들기
1. https://github.com/new 를 엽니다(GitHub 로그인).
2. Repository name에 `asset-data`, 아래에서 **Private**를 고르고 **Create repository**.

### 2. 토큰 만들기
1. GitHub 오른쪽 위 프로필 사진 → **Settings** → 왼쪽 맨 아래 **Developer settings** → **Personal access tokens** → **Fine-grained tokens** → **Generate new token**.
   (앱 설정 화면의 "토큰 만들기 화면" 링크를 누르면 이름·권한이 미리 채워질 수 있어요. 아래 값과 같은지만 확인하세요.)
2. 이렇게 채웁니다.
   - **Token name**: `asset-app`
   - **Expiration**: **No expiration** (짧게 두면 그날부터 앱이 멈춰요)
   - **Repository access**: **Only select repositories** → `asset-data` 하나
   - **Permissions → Repository permissions**:
     - **Contents**: Read and write
     - **Workflows**: Read and write (자동 시세 설정 파일을 만들기 위해)
3. **Generate token** → 나온 `github_pat_...` 토큰을 복사합니다. 이 화면을 닫으면 다시 볼 수 없어요.

### 3. 앱 연결
1. https://kimlin70-spec.github.io/asset/ → **설정**.
2. 데이터 저장소에 `내아이디/asset-data`(예: `kimlin70-spec/asset-data`), 토큰에 복사한 토큰을 넣고 **저장하고 시작**.
3. 앱이 알아서 빈 장부·시세·합계 파일과 자동 시세 설정을 만듭니다. 이미 있는 자료는 절대 덮어쓰지 않아요.

### 4. 처음 자료 넣기
1. 엑셀에서 아래 열 순서로 된 표를 준비합니다(예시는 가짜 값).

   | 계좌 | 자산군 | 이름 | 코드 | 수량 또는 금액 | 통화 | 단가 |
   |---|---|---|---|---|---|---|
   | 가나증권 종합 (홍길동) | 국내주식 | 삼성전자 | 005930 | 10 | | 70,000 |
   | 다라은행 (홍길동) | 현금 | 월급통장 | | 1,500,000 | | |

   - 자산군: 국내주식, 해외주식, 코인, 채권, 현금, 기타, 부채 중 하나
   - 코드: 주식·ETF는 종목코드(엑셀이 앞자리 0을 지워도 괜찮아요), 해외는 티커(AAPL), 코인은 기호(BTC). 현금·예금·채권은 비워요.
   - 통화: 비우면 원화. "달러", "USD"처럼 적어도 돼요.
   - 단가: 선택. 자동 시세가 처음 들어오기 전까지 쓰는 임시 값이에요.
2. 표 전체를 선택(Ctrl+A)해 복사(Ctrl+C)합니다.
3. 앱 **실사** 화면 → **처음 자료 넣기: 엑셀 표 붙여넣기** 칸에 붙여 넣기(Ctrl+V) → 미리보기 확인 → **붙여넣은 내용 저장**.
4. 1~2분 뒤 오른쪽 위 **↻**(새로 불러오기)를 누르면 자동 시세가 들어와요.

### 5. (선택) PC에 앱으로 설치
- 크롬: 오른쪽 위 ⋮ → **전송, 저장, 공유** → **페이지를 앱으로 설치**
- 엣지: 오른쪽 위 ⋯ → **앱** → **이 사이트를 앱으로 설치**
- (메뉴 이름은 브라우저 버전마다 조금 달라요.)

## 쓰는 법

### 평소: 생길 때마다 입력
- **매수·매도**: 종목, 수량, 정산금액(수수료·세금 포함, 실제로 움직인 돈). 모르면 "단가로"를 눌러 단가만 넣어도 돼요. 차이는 다음 실사 때 맞춰져요.
- **옮김**: 내 항목끼리 옮긴 것. 이체, 예금 가입·해지, 환전(받은 양을 따로 적기), 대출 받기(대출 → 통장), 대출 갚기(통장 → 대출).
  원리금을 한 번에 냈으면 보낸 양 = 통장에서 나간 돈, 받은 양 = 줄어든 원금으로 적어요(차이가 이자).
- **들어온 돈·나간 돈**: 배당, 이자, 큰 지출 등. **생활비·월급은 안 적어도 돼요.** 실사 때 차이로 잡혀요.
- 항목을 고르는 칸 어디서나 **+ 새 항목 만들기**로 새 종목·새 예금·새 대출·새 계좌를 만들 수 있어요.

### 두 달에 한 번: 실사
1. **실사** 화면에서 목록을 보고, 앱 값이 대충 맞으면 칸을 비워 두고, 다르면 실제 값을 적어요.
   - 증권 계좌 현금은 **D+2 예수금(추정 예수금)**을 적어요(매매를 체결일에 기록하기 때문).
   - 대출은 남은 빚을 양수로, 마이너스통장은 은행 앱처럼 마이너스로 적어요.
   - 그날 거래를 먼저 입력한 뒤 실사하세요.
2. **실사 저장**을 누르면 "지난 실사 이후 기록 안 한 현금 흐름(수입 − 지출)"이 나와요.
   마이너스면 그 기간 생활비 등으로 그만큼 더 쓴 거예요. 현황 화면에도 계속 보여요.
3. 마지막 실사가 60일을 넘으면 현황에 "실사할 때예요"가 떠요.

### 값만 틀렸을 때
현황의 **보유 목록**에서 항목을 누르면 이름·코드를 고치거나 **값 바로잡기**(액면분할, 빠뜨린 입금 등)를 할 수 있어요.

### 시세
- 매일 아침 06:47 무렵, 장부를 저장할 때, 직접 실행할 때 GitHub가 자동으로 받아요(내 데이터 저장소의 Actions).
- 지금 바로 받으려면: `github.com/내아이디/asset-data` → **Actions** → 왼쪽 **시세 갱신** → **Run workflow** → 1~2분 뒤 앱의 ↻.
- 실시간일 필요는 없어서 **전날 종가 기준**이면 충분해요. 출처도 내가 거래하는 곳일 필요 없이 공개된 시세를 써요:
  국내 네이버·야후, 해외 야후, 코인 업비트·야후, 환율 야후·[ExchangeRate-API](https://www.exchangerate-api.com)(Rates By Exchange Rate API).
- 비공식 출처라 가끔 못 받을 수 있어요. 하루 이틀은 이전 가격을 조용히 쓰고, 3일 넘게 못 받으면 보유 목록에 "시세 N일 전 것"으로 표시해요.

## 문제가 생기면
- **"토큰이 만료됐거나 잘못됐어요"**: 2번을 다시 해서 새 토큰을 만들고 설정에 넣어요.
- **"토큰 권한이 모자라요"**: 토큰의 Contents와 Workflows가 Read and write인지, 저장소가 `asset-data`로 골라져 있는지 확인해요.
- **앱을 고쳤다는데 화면이 그대로**: Ctrl+F5(강력 새로고침).
- **시세가 며칠째 안 바뀜**: 데이터 저장소의 Actions 화면에서 빨간 실패가 있는지 봐요. 그래도 모르겠으면 그 화면을 캡처해 물어보세요.
- **잘못 저장했어요**: 기록 화면에서 고치거나 지울 수 있어요. 데이터 저장소의 모든 저장은 GitHub에 기록(History)으로 남아 이전 상태로 되돌릴 수도 있어요.

## 보안
- 토큰은 이 브라우저(localStorage)에만 저장돼요. 다른 PC나 브라우저에서는 다시 넣어야 해요.
- 토큰은 `asset-data` 저장소 하나에만 쓸 수 있어요.
- 이 계정(`kimlin70-spec.github.io`)으로 다른 GitHub Pages 사이트를 만들 때는 외부 스크립트를 넣지 마세요. 같은 주소 아래라 토큰을 읽을 수 있어요.
